Back up your home folder to any storage you own. Free and open source.

Why Stashling?

Encrypted on your computer

Your files are encrypted with your own key before upload. The storage provider only ever sees noise.

Stores each piece once

Deduplication splits files into chunks and keeps every chunk only once, so a year of daily backups stays small.

Fast after the first run

After the first backup, Stashling reads only the files that changed. A typical nightly run takes under five minutes.

Any storage you like

Use a USB drive, a folder on your NAS, an SFTP server or any S3-compatible bucket. Switch any time.
